# 🧠 Autonomous AI Research Agent

This project is a full-stack GenAI application designed to assist users in exploring and understanding research papers efficiently.

The system allows users to search real research papers from arXiv, read detailed paper information, generate insights, and ask questions based on the selected paper.

It combines modern AI concepts like Retrieval-Augmented Generation (RAG), AI agents, and LLM-based reasoning to simulate how intelligent research assistants work.

---

## 🚀 Features

- 🔍 Search real research papers using arXiv API  
- 📄 Read detailed information of selected papers  
- 💡 Generate insights based on the research topic  
- ❓ Ask questions and get answers from paper context  
- 🎨 Attractive and user-friendly UI (not typical dark AI UI)

---

## 📌 Workflow

1. User searches a research topic  
2. System retrieves papers from arXiv  
3. User selects a paper  
4. System reads paper details (abstract)  
5. Insights are generated  
6. User asks questions → answers are generated using paper context  

---

## 🎯 Objective

To build a system that goes beyond simple search and acts as an intelligent research assistant by combining search, understanding, and reasoning capabilities.
